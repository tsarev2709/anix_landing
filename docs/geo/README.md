# GEO Anix — протокол и реализация

Версия вопросов: 2026-09-11-v1. Язык: русский. Целевой рынок: РФ. Это гипотезы запросов покупателей, не частотности Wordstat.

## Четыре независимых уровня

1. Доступность: HTTP, статический текст, заголовок, canonical, sitemap, отсутствие noindex у публичных страниц.
2. Обнаружение источника в web search: возвращённые URL, релевантность, ошибки. Это не позиция в Яндексе/Google и не рекомендация нейросети.
3. Ответ конкретного сервиса: платформа, видимый режим/модель, новый диалог без контекста Anix, точный вопрос, время, текст ответа, ссылки. Для повторяемости — три прогона одного вопроса с одинаковыми условиями. API и интерфейсные ответы не объединяются.
4. Переход, квалифицированная заявка, сделка: разные события, не заменяющие друг друга.

## Исходный замер

В `prompts.json` — 80 вопросов, 8 кластеров по 10. В `search-baseline-2026-09-11.json` — фактически возвращённые поиском URL.
По свободным формулировкам много нерелевантных результатов, в том числе The Anix и одноимённые проекты. Ни в одном из сохранённых 80 поисковых ответов не вернулся URL основного домена. Это характеристика этого поискового прохода, НЕ «0% GEO-видимости» и НЕ доказательство отсутствия сайта в индексе. Дополнительный отдельный запрос `"Anix Studio" "медицинская"` вернул главную и `/why_it_works/`; он не смешивается с исходным набором. Прямое чтение сайта также успешно. Реальные ответы ChatGPT, Алисы, Perplexity не измерены: `not_measured`, а не ноль.

## Реализация

- `src/content/geoContent.json`: единый источник десяти справочных материалов, страницы маскотов, фактов, контекстных FAQ и дополнений трёх кейсов.
- `scripts/ensure-geo-source.js`: идемпотентная регистрация 13 страниц (с хабом) в существующей SEO-сборке, связи с услугами и генерация `public/anix-facts.json`.
- `GeoGuidePage`: видимая страница для людей, без отдельного контента «только для ботов».
- `GeoContextPortal`: те же уточнения, что попадают в статический HTML, на существующих страницах.
- Organization `@id` единый; Article-разметка статического HTML и клиента генерируется одной функцией.
- FAQ включены в статический текст. Внешние ссылки больше не получают лишний завершающий слеш от генератора.
- Sitemap больше не объявляет все страницы обновлёнными при каждой технической сборке; lastmod есть только при известной дате редакции.
- Скрытый профиль Андрея и удалённый РЧК не возвращаются в индекс.
- `llms.txt` не добавлен: не обязательный стандарт и не доказанный механизм рекомендации. `anix-facts.json` — удобная копия видимых сведений, не отдельный фактор ранжирования.

## Атрибуция

`aiReferral.js` распознаёт точные домены и их поддомены, не принимает `chatgpt.com.evil.test` за ChatGPT. При конфликте с существующим UTM не переписывает источник. Google/Bing/Яндекс без явного AI-источника не классифицируются как AI-переход. Отсутствие referrer остаётся неизвестным/direct.
Событие `ai_referral_visit` отправляется через существующую аналитику (поля provider, evidence, conflict, path; без текста диалогов). На сервере добавлено разрешённое имя события. UTM, initial_referrer, landing_page и source уже сохраняются формой в website_leads и передаются в заметку AmoCRM; их схема не менялась. Новые страницы подключены к существующей форме. Доставка реального лида в production требует отдельной безопасной сквозной проверки; по одному просмотру страницы её считать подтверждённой нельзя.

Для отчёта по новым событиям используйте существующую защищённую аналитику lead_events. Для отчёта по заявкам — сохранённые source, utm_source, initial_referrer и landing_page в website_leads. Не открывайте таблицы публично и не помещайте service-role ключи в клиент.

## Проверки

`npm run build`; `node scripts/verify-geo-build.js`; `CI=true node node_modules/react-scripts/bin/react-scripts.js test --watchAll=false --runInBand --runTestsByPath src/__tests__/aiReferral.test.js`.
В клонированном репозитории node_modules и lockfile рассинхронизированы с package.json. Локальные изменения зависимостей для запуска проверок не включаются в GEO-коммит. Не заменяйте lockfile или весь node_modules в рамках контентной задачи.

## Мониторинг

Еженедельная проверка по пятницам около 11:00 МСК, начиная с 18.09.2026. Сохранять условия замера. Не менять сайт автоматически. Не считать неподтверждённые или недоступные ответы нулевым упоминанием.

## Основания и ограничения

- Google: https://developers.google.com/search/docs/appearance/ai-features — важен доступный полезный текст; специальная AI-разметка не требуется; индексирование и показ не гарантированы.
- Производственный кейс Agentura/КТК: https://agentura.studio/sozdanie-obuchayushchego-videokontenta-dlya-ktk — образец сочетания персонажа и библиотеки материалов. Заявления об эффекте принадлежат автору кейса, не подтверждают причинность.
- Radar/CYBERSTEEL: https://www.sostav.ru/publication/radar-sozdal-maskota-kiberkota-72067.html — пример публикации с именованным представителем клиента и описанием носителей. Не доказательство эффекта для Anix.
- Публикация с A. V. Tsarev: DOI 10.3390/md16110401; PMID 30360541. Биофизическая экспертиза не обозначается как клиническая квалификация.
