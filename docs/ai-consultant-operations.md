# AI-консультант Anix: эксплуатация базы знаний

## Где что хранится

- Публичные кейсы и разрешённые материалы: `data/ai-public-cases.json`.
- Генератор таблиц кейсов: `scripts/generate-ai-case-catalog-sql.mjs`.
- Общая политика ответов: `supabase/functions/_shared/ai-grounding.mjs`.
- Версия системного промпта в Supabase: таблица `ai_chat_prompts`; изменения вносятся новой миграцией, а не ручной правкой активной строки.
- Текстовые документы и страницы сайта: `knowledge_sources`, `knowledge_documents`, `knowledge_chunks`.
- История диалогов: `ai_chat_sessions`, `ai_chat_messages`.
- Диагностика: service-only views `ai_chat_quality_diagnostics` и `ai_chat_quality_daily`.

## Как добавить или изменить публичный кейс

1. Проверить, что страница и все факты уже опубликованы на `studio.anix-ai.pro`.
2. Изменить `data/ai-public-cases.json`. Не добавлять внутренние цены и личные контакты.
3. Для файла или видео добавить URL в `imageUrl` / `videoUrl` только если материал реально существует и его можно публично отправлять.
4. Выполнить:

   ```bash
   npm run ai:catalog:generate
   npm run test:rag-quality
   ```

5. Закоммитить каталог и обновлённую SQL-миграцию. Для уже применённой миграции создать следующую миграцию, не переписывать историю production.

## Как загрузить текстовые файлы

Скрипт запускается там, где доступны локальный gateway и приватный env-файл:

```bash
npm run knowledge:ingest -- "C:\Anix\knowledge\Файл.txt" \
  --source-slug anix-general \
  --source-title "Общая база знаний Anix" \
  --vertical general \
  --env "C:\Anix\knowledge.env" \
  --verify
```

Секреты не передавать в аргументах и не коммитить. Неизменённый документ пропускается по checksum. `--force` нужен только для осознанного полного переиндексирования.

Если файл не загружен в `knowledge_chunks` и не зарегистрирован как публичный asset кейса, консультант не должен предлагать его посетителю. Вместо этого он направляет в форму или `@anix_helper`.

## Как обновить знания с публичного сайта

```bash
npm run knowledge:ingest:site -- --env "C:\Anix\knowledge.env"
```

Скрипт берёт только индексируемые страницы sitemap, извлекает основной контент `<main>`, исключает меню, формы и footer, режет текст по заголовкам и проверяет self-retrieval каждого изменившегося документа.

## Обязательные проверки перед production

```bash
npm run lint
npm run typecheck:edge
npm run check:ai-scripts
npm run test:rag-quality
CI=true npm test -- --watchAll=false
npm run build
```

Деплой выполняется только через PR и зелёные GitHub Actions. Если миграция или Edge Function не применились, не переключать чат вручную: production должен остаться на последней рабочей версии.

## Быстрая проверка после деплоя

Проверить в новом диалоге:

1. `Расскажи про ваши кейсы с фармкомпаниями` — Hemotech AI, Мосфарма, Авиандр.
2. `Дай конкретные названия и ссылки` — только карточки реально существующих страниц.
3. `Подробнее про Мосфарму` — задача, решение, результат.
4. `Расскажи про Aventis` — явный отказ придумывать кейс.
5. `Пришли PDF по Мосфарме` — предложение запросить файл, если PDF не зарегистрирован.
6. `Сколько стоит минута ролика?` — ориентир 300 тыс.–1,5 млн ₽.
7. Сообщение с собственным контактом — прежний сценарий синхронизации с amoCRM.
